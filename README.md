# SVARAVITA

SVARAVITA is an accessible educational web game designed for visually impaired users to learn about balanced nutrition through interactive storytelling, voice guidance, and quizzes.

## Features

- 🎙️ Full voice-guided gameplay
- 📖 Interactive storytelling
- 🧩 Multiple-choice nutrition quizzes
- 👆 Single tap to replay choices
- 👆👆 Double tap to select answers
- ⭐ Level progression system
- 💚 Vita Point scoring
- 💾 Local progress saving
- ♿ Accessibility-first design

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES Modules)
- Event-Driven Architecture
- LocalStorage
